# FreshCut CRM

A polished Next.js CRM starter for a Fresh-Cut Vegetables / Ready-to-Cook / Subscription business.

## Included
- Executive dashboard
- Lead & customer pipeline
- Add Lead modal
- Orders desk
- Product catalog & stock indicators
- Tasks & follow-up desk
- AI Growth Assistant placeholder
- Responsive mobile navigation
- Professional green/white food-tech UI
- Demo data ready to replace with a real database

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000
